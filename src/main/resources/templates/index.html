Enterprise Multi-Tier Architecture

Engineered following strict Separation of Concerns (SoC) across Controllers, Services, Repositories, and Security layers with Hibernate ORM persistence and MySQL/H2 database support.

Role-Based Access Control (RBAC)

Strict segregation between regular fitness members (ROLE_USER) and administrative supervisors (ROLE_ADMIN).

Granular Metric Tracking

Dynamic calculation of BMI, calorie burn rates, training duration distributions, and goal progress percentages.

Challenge Progression Engine

Automated leaderboard calculations, participant milestones, and completion badge awards.

Execution Pipeline Spring MVC
1. Browser Client: HTML5 / CSS3 / JavaScript / Bootstrap 5 Client Tier
2. Thymeleaf Engine: Server-Side UI Rendering View Tier
3. Spring Controllers: Routing & Parameter Binding Web Tier
4. Business Service Layer: Domain Rules & Transaction Boundaries Logic Tier
5. Spring Data JPA & Hibernate: ORM Mapping & Repositories Data Tier
6. MySQL / Persistent DB: Structured Relational Storage RDBMS
